## Selected Projects

### First Call Flow — Multi-Tenant Agentic Operations Platform

Building a multi-tenant AI operations platform for home-services businesses. Each tenant can operate branded AI voice intake, lead management, estimating, scheduling, CRM integration, messaging, and field workflows from a shared platform with tenant-specific configuration.

The system combines AI agents with deterministic workflows and human approval rather than using an LLM for every action. Current capabilities include:

* AI voice intake and structured lead qualification
* Agent-driven lead routing, scheduling, estimating, and follow-up
* Hermes-based AI operations assistant with SMS and Telegram interfaces
* JobNimbus synchronization and external API/tool integration
* Deterministic command paths for routine, latency-sensitive operations
* Multi-tenant configuration, branding, staff pools, and workflow isolation
* Human approval and escalation for higher-impact actions
* Image-based field intelligence experiments using multimodal models

I'm using the project to explore how agentic systems should divide work between models, tools, deterministic software, and humans in a production business workflow.

### AI Job Search Assistant

Building a personal agentic job-search system that gathers opportunities from multiple sources, evaluates relevance, maintains application state, and posts high-fit opportunities and scheduled digests to Telegram.

The project combines:

* Multi-source job ingestion and normalization
* AI-assisted fit evaluation and prioritization
* Duplicate detection and application tracking
* Company and role research
* Telegram notifications and conversational workflows
* Interview-preparation context
* Scheduled and background agent workflows
* Local and hosted model experimentation

I'm using it to test agent orchestration, context management, model routing, reliability, and where deterministic logic works better than an LLM.
